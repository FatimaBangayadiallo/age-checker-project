🧓 Age Checker App
A simple web app that checks a user's age and displays a personalized message based on the input.

🌟 Features
Collects user input through a form

Validates the age input

Displays custom messages based on age:

If under 18 → ❌ "Access denied. You're too young."

If exactly 18 → 🎉 "Congratulations on becoming an adult!"

If over 18 → ✅ "Access granted."

If input is empty or not a number → ⚠️ "Please enter a valid number."

🛠️ Built With
HTML5

CSS3

JavaScript (DOM manipulation and form handling)
